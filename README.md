# Number-Based Programs Using For Loops (C++)
A collection of beginner-friendly C++ programs that solve different number-related problems using `for` loops.

# Programs Included
| No. | Program | Description |
|---|---|---|
| 1 | Armstrong Number in Range | Finds Armstrong numbers within a given range. |
| 2 | Count Divisors | Counts the total number of divisors of a given number. |
| 3 | Fibonacci Series | Generates the Fibonacci series up to a given limit. |
| 4 | Harshad Number in Range | Finds Harshad numbers within a given range. |
| 5 | Palindrome Numbers in Range | Finds palindrome numbers within a given range. |
| 6 | Perfect Number in Range | Finds perfect numbers within a given range. |
| 7 | Prime Number in Range | Displays all prime numbers within a given range. |
| 8 | Prime Number Checker | Checks whether a given number is prime. |
| 9 | Reverse Number | Reverses the digits of a given number. |
| 10 | Strong Number Checker | Checks whether a given number is a Strong number. |
